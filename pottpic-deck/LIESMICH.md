# Pottpic Deck – Chrome-Erweiterung

Alle Seiten, die du täglich brauchst, als Knöpfe oben rechts in Chrome.

- `kacheln.js` – **hier stehen alle Knöpfe und Gruppen** (eine Zeile pro Knopf). Nur diese Datei musst du anfassen.
- `deck.html`, `deck.css`, `deck.js` – Aufbau, Aussehen, Technik
- `manifest.json` – Ausweis der Erweiterung für Chrome
- `icons/` – das Symbol (vier farbige Quadrate)

## Laden
1. Ordner `pottpic-deck` auf deinen Rechner an 'nen festen Platz legen (nicht mehr verschieben).
2. In Chrome `chrome://extensions` öffnen.
3. Oben rechts **Entwicklermodus** anschalten.
4. **„Entpackte Erweiterung laden“** → Ordner `pottpic-deck` wählen.
5. Puzzle-Symbol oben rechts → beim Pottpic Deck auf die **Stecknadel** klicken.

## Neuen Knopf hinzufügen
1. `kacheln.js` mit einem Texteditor öffnen.
2. Eine Zeile kopieren, darunter einfügen, Name / Adresse / Zeichen / Gruppe ändern.
3. Speichern → `chrome://extensions` → beim Pottpic Deck auf **↻** klicken.
