# Napfzeit 🐾

Monis eigener Kalorien-, Gewichts- und Wasser-Tracker als Web-App fürs iPhone.

- **Tagebuch:** Kalorienziel, Frühstück/Mittag/Abend/Snacks, Makros, Wasser-Gläser
- **Lebensmittel:** Suche + Barcode-Scanner über Open Food Facts, Basics (Richtwerte), eigene Lebensmittel, „Nur Kalorien“
- **Gewicht:** Einträge mit Verlaufskurve
- **Profil:** Kalorienziel ausrechnen (Mifflin-St-Jeor, Schätzung), Makros, Wasserziel, Sicherung speichern/laden

Alle Daten bleiben lokal auf dem iPhone (localStorage). Kein Login, kein Server.

## Aufs iPhone
1. Seite in **Safari** öffnen (z. B. über GitHub Pages: `…/napfzeit/`)
2. Teilen-Symbol → **Zum Home-Bildschirm**
3. Ab dann startet Napfzeit wie 'ne normale App.
